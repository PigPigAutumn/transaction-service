Type: POST

Author: Jiaqi HUANG

Content-Type: application/json

Description: create transaction

Body-parameters:

true

-

amount

number

Transaction amount.
Positive values represent income and negative values represent expenditure.

true

-

balance

number

Post-transaction account balance.

false

-

type

string

Transaction type.
The following values are available: TRANSFER, DEPOSIT, WITHDRAW, PAYMENT. Validate[regexp: ^[a-zA-Z0-9_ ]{1,16}$; ]

true

-

status

string

Transaction status.
The following values are available: SUCCESS, FAILED, PROCESSING. Validate[regexp: ^[a-zA-Z0-9_ ]{1,16}$; ]

true

-

counterparty

string

Counterparty information. Validate[regexp: ^[a-zA-Z0-9_ ]{1,64}$; ]

true

-

description

string

Transaction description. Validate[regexp: ^[a-zA-Z0-9_ ]{1,128}$; ]

false

-
